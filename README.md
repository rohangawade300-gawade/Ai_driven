Sales Data Analysis Using Python

Project Overview

This beginner-level project analyzes sample sales data using Python, Pandas, and Matplotlib.

Objectives

- Calculate total revenue for each product.
- Compare monthly sales revenue.
- Identify the best-selling product.
- Visualize sales performance using bar charts.

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

Key Insights

- Laptop generates the highest total revenue.
- Headphones have the highest number of units sold.
- February has the highest monthly revenue.

Dataset

The project uses sample sales data created for learning purposes.
